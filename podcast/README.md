# פודקאסט הבוקר

פרק של כ-10 דקות (950–1150 מילים ביום עם חומר חדש, או 850–1150 מילים ביום בלי חומר חדש כשיש עומק ומטלה פתוחה; עם חיבור מפורש לשיעורים קודמים) **לכל קורס פעיל**, כל אחד רק על הקורס שלו, להאזנה בבוקר לפני השיעורים. שני קולות: הילה ואבי (קולות עבריים של edge-tts).

## איך זה עובד

```
site.json (מערכת השעות, מועדים, הגשות, הודעות)  ┐
קטלוג: מצגות, סילבוס, פורומים, ההגשות שלי        ├─> podcast_context.py ─> context\<קורס>\<תאריך>.json
kb: קשרים בין קורסים (prereqs, concepts)         ┘                              │
                                                       Claude כותב תסריט (שלב הכתיבה, לפי podcast_daily_prompt.md)
                                                                                 ▼
                                    פודקאסט\<קורס>\<תאריך>.md ─> podcast_tts.py ─> <תאריך>.mp3 + episodes.json
```

1. **הקשר** (`podcast_context.py <מפתח-קורס> <תאריך>`): קוד בלבד, בלי מודל. אוסף את כל מה שהפרק צריך לקובץ JSON אחד: סיכום האם יש שיעור היום (`today_summary`), **שדרת הקורס המצטברת (`course_spine` ו-`all_lectures`) מהרצאה 1 ועד היום** (כותרות, הגדרות, משפטים ולמות מכל המצגות בסמסטר), הטקסט המלא של המצגות החדשות, תכנית הסילבוס, **טקסט השאלות המלא של עבודות הבית (`questions_text`) ומיפוי ההרצאות הקשורות לכל עבודה (`related_lectures`)**, הודעות סגל, ומושגי רקע מקורסים קודמים לחיבור בפרק. `--list-active` מדפיס את הקורסים הפעילים.
2. **תסריט, לינט וסימולציות דו-ממדיות:** התסריט נכתב ל-`פודקאסט\<קורס>\<תאריך>.md` לפי `study-briefing\podcast_rules.md` (בלי ניקוד בתסריט, תורות ומשפטים קצרים, רעיון אחד לפרק) ועד 2 בלוקים של ` ```visual ` עם נוסחאות LaTeX ושדה `"sim"` הצהרתי ב-`POD_SIM` (`geom2d`, `automaton`, `pumping_gaps`, `sequence_net`, `fn_plot`) בלי `"svg"`. לפני ההקראה מריצים `podcast_lint.py <תסריט> --dict study-briefing\podcast_pronounce.json`.
3. **מילון הגייה והקראה** (`podcast_tts.py <תסריט>`): אינו מנקד את קובץ ה-`.md`; בזמן ההקראה מחיל ניקוד רק מתוך מילון ההגייה `study-briefing\podcast_pronounce.json` (`words`, `phrases`), מתרגם מונחים לטיניים (`latin`, `pending`, ושורת `<!-- terms: ... -->` שנרשמת ב-`pending` לאישור חד-פעמי) ואותיות בודדות מטבלת האותיות (`letters`), ומסנתז ב-`edge-tts` בקצב `-12%` עם הפסקות של `0.4` שניות בין תורות ו-`1.2` שניות בין פרקים. `--check` בודק תסריט ואיורים בלי רשת; `--sync-metadata` מעדכן איורים ופרקים ב-`episodes.json` בלי לסנתז אודיו מחדש.
4. **האתר** קורא את `פודקאסט\<קורס>\episodes.json`: כולל `chapters` ו-`visuals` (מעבדות אינטראקטיביות גדולות + דיאגרמות SVG + נוסחאות KaTeX המתחלפות אוטומטית מתחת לנגן לפי הפרק המתנגן, עם אפשרות הרחבה לרוחב מלא).

הנחיית הלילה המדויקת, שרצה לכל קורס: `study-briefing\podcast_daily_prompt.md`.

## איפה מה רץ

כרגע **הכול על המחשב הזה**.

- ל-`podcast_context.py` מספיק Python רגיל. הוא בונה מחדש את `site.json` (`site\build.py`) כשהוא ישן מ-18 שעות.
- `podcast_tts.py` רץ בתוך סביבה ייעודית, `%LOCALAPPDATA%\study-briefing\podcast_venv` (שם מותקן `edge-tts`), והוא מפעיל את עצמו בתוכה לבד. ffmpeg נלקח מ-PATH, מ-`STUDY_FFMPEG`, או מהחבילה `imageio-ffmpeg` שכלי ההקלטות כבר משתמשים בה. אין `ffprobe`, והאורך נמדד דרך ffmpeg.
- edge-tts צריך אינטרנט ושולח את טקסט התסריט לקולות המקוונים של מיקרוסופט (באישור של לירן). אם אין חיבור, הסקריפט אומר את זה, משאיר את התסריט ולא יוצר אודיו (קוד יציאה 2).

**בשרת, בהמשך:** הקשר וההקראה יכולים לרוץ שם (Python רגיל, `edge-tts` ו-ffmpeg בסביבה אחת, אותם נתיבים יחסיים). שלב התסריט דורש הרצה של Claude, ולכן הוא נשאר משימה מתוזמנת עם גישה לעץ.

## מה לדעת

- נבדק: הפרקים נוצרים מקצה לקצה, האורך והפרקים נמדדים. **לא נבדק בשמיעה:** איך הקולות מבטאים מושגים מתמטיים. לכן התסריט כותב הכול במילים (מספרים, אותיות, קיצורים), ו-`PRONOUNCE` ב-`podcast_tts.py` מכיל תרגום של קיצורים נפוצים.
- מערכת השעות היא הדפוס השבועי של הפורטל. ביטול או הזזה מופיעים רק בהודעות הסגל, ולכן הן חלק מההקשר.
- סילבוס בלי תאריכים (מודלים חישוביים, שיטות גיאומטריות): הפרק אומר את הסדר ולא ממציא תאריכים.
- קובץ תרגול בלי טקסט בקטלוג נקרא לפי הכותרת בלבד.
- כשקורס מסתיים או מתווסף, אין מה לעדכן: הוא נכנס לרשימה ברגע שהוא מסומן כפעיל בסמסטר הנוכחי ב-`site.json`. מחקר (התזה) לא נכלל עד שיהיה בו משהו אמיתי.
